# Djibril Naji — Portfolio

Personal portfolio, available in French (`/`) and English (`/en`), with light and dark themes.

Built with TanStack Start, React 19, Tailwind CSS v4 and Nitro.

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Content

- `src/i18n/fr.ts` and `src/i18n/en.ts`: every visible text, per language
- `src/data/portfolio.ts`: language-neutral data (links, stacks, logos)
- `src/styles.css`: colour tokens for both themes
